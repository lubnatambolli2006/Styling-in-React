# Styling in React

## Assignment: Styling in React

This project demonstrates different styling techniques used in React applications.

## Technologies Used

- React
- HTML
- CSS
- JavaScript

## Styling Techniques Demonstrated

### 1. Inline Styling
React inline styles are used for the main heading.

### 2. External CSS
The `style.css` file is used for layout, colors, spacing, cards, navigation and other styles.

### 3. CSS Grid
CSS Grid is used to create the styling technique cards.

### 4. Flexbox
Flexbox is used for the navigation layout.

### 5. Responsive Design
Media queries make the website responsive on mobile and desktop screens.

### 6. React State
The `useState` hook is used to change the message when the button is clicked.
